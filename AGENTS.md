# Project instructions

- Inspect relevant files before modifying them.
- Implement only the requested milestone; keep changes focused and avoid unnecessary files.
- Use a simple modular architecture and minimal dependencies. Avoid unnecessary abstractions, microservices, queues and enterprise infrastructure.
- Use Python typing, clean code and appropriate tests.
- Never execute uploaded or untrusted code on the host.
- Never assume a generated patch is secure just because tests passed.
- Never delete or overwrite datasets or user files without authorization.
- Never run destructive Git commands.
- Avoid installing heavy packages, Docker or WSL, or downloading AI models unless a future milestone explicitly requires them.
- Prefer project environments and large files on E:.
- Update PLAN.md and README.md when milestone status or setup changes.
- Run relevant checks and tests; report actual results and limitations.
